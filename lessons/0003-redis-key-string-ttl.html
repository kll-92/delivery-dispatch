Redis 第一项实操：Key、String 与 TTL

目标：亲手把“骑手 2 的临时缓存”写入 Redis，读出来，再确认它会自动过期。

先理解三个词

词可以把它想成项目例子
Key储物柜编号rider:detail:2
Value柜子里的物品骑手 2 的详情 JSON
TTL柜子自动清空前的倒计时10 分钟后自动失效

在终端执行

docker exec -it delivery-redis redis-cli

SET rider:detail:2 '{"id":2,"name":"李四"}'
GET rider:detail:2
EXPIRE rider:detail:2 60
TTL rider:detail:2
DEL rider:detail:2

SET 写入，GET 读取，EXPIRE 设定 60 秒过期，TTL 看剩余秒数，DEL 删除。

为什么缓存必须有 TTL？

如果骑手详情永不过期，而数据库中的姓名、手机号已更新，Redis 仍可能返回旧数据；同时无用 Key 会不断积累并占用内存。TTL 让缓存自动失效，下一次查询再从 MySQL 取新数据。
