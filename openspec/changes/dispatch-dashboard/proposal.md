# 配送调度后台前端

## 为什么做

当前项目已经有完整的 Spring Boot 后端接口，但主要通过 Swagger 调试。为了让项目更接近真实系统，也便于作品集展示，需要增加一个可视化的配送调度后台。

## 目标

使用一个轻量级前端页面展示骑手、订单和派单结果，并让用户可以通过页面调用现有后端接口。

## 本次范围

- 骑手列表与骑手状态查看
- 订单列表与订单状态查看
- 手动派单和自动派单
- 订单开始配送、完成、取消
- 附近骑手查询
- 加载中、空数据、请求失败等页面状态

## 暂不做

- 登录和权限系统
- 支付功能
- 复杂地图 SDK 接入
- 生产环境监控大屏
