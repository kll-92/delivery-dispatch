JVM 快速参考：同城配送项目

词人话项目对应
JVM运行 Java 字节码并管理运行环境的程序启动 Spring Boot 的 bin/java
堆主要放 Java 对象的内存区Rider、订单、JSON 对象
栈线程执行方法时的临时工作区Controller → Service → Mapper 的调用过程
垃圾回收清理不再可达的对象请求产生的临时对象被回收
JIT把常用字节码优化成更快的机器码高频请求路径的运行优化

项目关系

Java 21 JVM
  └── Spring Boot
      └── 内嵌 Tomcat + Controller/Service/Mapper
          ├── 网络连接 MySQL
          └── 网络连接 Redis

MySQL 和 Redis 是独立服务，不和 Spring Boot 共用同一个 JVM。

当前边界

项目已经运行在 JVM 上，但目前没有专项配置堆大小、垃圾回收器或 GC 日志；Actuator 只负责观察指标。
